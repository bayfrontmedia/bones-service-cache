# Cache service

The Cache service adds event and filter-based caching to an app built 
using the [Bones](https://github.com/bayfrontmedia/bones) framework.

## Exceptions

All exceptions thrown by the Cache service extend `Bayfront\BonesService\Cache\Exceptions\CacheServiceException`,
so you can choose to catch exceptions as narrowly or broadly as you like.
