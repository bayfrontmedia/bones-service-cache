# Cache service: Filters

The following [filters](https://github.com/bayfrontmedia/bones/blob/master/docs/services/filters.md) are added by this
service:

- `cache.item.save`: Filters the cache item as a [CacheItemInterface](https://github.com/bayfrontmedia/php-cache/blob/master/docs/interfaces/cacheiteminterface.md) 
before being saved.
